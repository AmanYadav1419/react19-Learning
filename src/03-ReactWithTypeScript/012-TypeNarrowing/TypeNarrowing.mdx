# Type Narrowing :- 

- Type narrowing is the process of refining a variable's type within a conditional block of code.
- This allows you to write more precise and type-safe code.

- How will achieve the type narrowing 👇
- `Typescript` provides serveral mechanisms for narrowing types.
    - Type guards
    - The instance operator
    - intersection types
    - Discrimiated unions
- Note :- in this specific sections we are learning about , `Type guards`, `The instance operator` and `intersection types` only.


## Type guards 👇

- Type guards are mechanisms that help Typescript understand and narrow down the types more precisely.
- one common type guard is `typeof operator`.
- how the code is gonna look like , here is the code 👇

```ts
// Define union type
type myType = string | number;

// Example function with type guard.
// defines parameter annoted with myType and return is void
// as we are not returning any value from function.
function ExampleFunction(value: myType): void {
  // Type guard using typeof
  if (typeof value === "string") {
    // Within this block typescript knows the `value` is `string`.
    console.log(value.toUpperCase());
  } else {
    // Within this block typescript knows the `value` is `number`.
    console.log(value.toFixed(2));
  }
}

// Example usage
ExampleFunction("hello"); //output :- HELLO
ExampleFunction(10); //output :- 10.00

```
