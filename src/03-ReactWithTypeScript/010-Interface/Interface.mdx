# Interface :-

- Interface is a way to define a `contract` for the shape of an object.
- It specifies the `properties and their types that an object must have`.
- Interfaces are a powerful tool for enforcing a certain structure in your code.

-here is the example of the Interface

```ts
// Interface Definition
interface person {
  name: string;
  age: number;
  email: string;
}

// Usage
const John:person = {
    name:"Jhon",
    age:"20,
    email:"jhon@test.com"
}
```

- While interfaces are commonly used to define the structure ob objects, they `are not limited to just objects`.
- Interfaces in Typescript can also be used to `describe the shape` of function and classes.

- here is the details and examples

## Interface for Functions

- here is the example of interface for functions 👇.

```ts
// Interface for a function
interface MathOperation {
  // so a function accepts to parameter both are type annoted as number ,
  // and the return value of the function is also type annoted as number
  (x: number, y: number): number;
}

// Usage of the Interface

// in here we are annoted the functions with the interface MathOperation
const add: MathOperation = (a, b) => a + b;
const subtract: MathOperation = (a, b) => a - b;

console.log(add(6, 4)); // output :- 10
console.log(subtract(5, 2)); //output :- 3
```

## Interface for Classes

- here is the example of interface for classes 👇.

```ts
// Interface for a class
interface Vehicle {
  // as we are not returning any value from the function that is why void is annoted for the function.
  start(): void;
  stop(): void;
}

// Class Implementing the Interface

// and here we are using keyword `implements` not extends.
// to implement/define the function call.
class Car implements Vehicle {
  // start function
  start() {
    console.log("Car Started ");
  }

  // stop function
  stop() {
    console.log("Car Stopped");
  }
}

// Usage
const myCar = new Car();
myCar.start();
myCar.stop();
```
