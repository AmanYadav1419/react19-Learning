# Interface :-

- Interface is a way to define a `contract` for the shape of an object.
- It specifies the `properties and their types that an object must have`.
- Interfaces are a powerful tool for enforcing a certain structure in your code.

-here is the example of the Interface

```ts
// Interface Definition
interface person {
  name: string;
  age: number;
  email: string;
}

// Usage
const John:person = {
    name:"Jhon",
    age:"20,
    email:"jhon@test.com"
}
```

### More Examples of Interfaces, as Interfaces are supremly important 👇

```ts
interface Computer {
  processor: string;
  ram: number;
  hdd: number;
}

const ComputerExample: Computer = {
  processor: "i7",
  ram: 16,
  hdd: 512,
};

console.log(ComputerExample.processor); // Output:- i7
console.log(ComputerExample.ram); // Output:- 16
console.log(ComputerExample.hdd); // Output:- 512
```

- While interfaces are commonly used to define the structure ob objects, they `are not limited to just objects`.
- Interfaces in Typescript can also be used to `describe the shape` of function and classes.

- here is the details and examples

## Interface for Functions

- here is the example of interface for functions 👇.

```ts
// Interface for a function
interface MathOperation {
  // so a function accepts to parameter both are type annoted as number ,
  // and the return value of the function is also type annoted as number
  (x: number, y: number): number;
}

// Usage of the Interface

// in here we are annoted the functions with the interface MathOperation
const add: MathOperation = (a, b) => a + b;
const subtract: MathOperation = (a, b) => a - b;

console.log(add(6, 4)); // output :- 10
console.log(subtract(5, 2)); //output :- 3
```

- next example of the function with Interfaces 👇

```ts
// Defining Interface
interface Person {
  firstName: string;
  lastName: string;
  age?: number; // this is optional parameter added (?) after the key.
  sayHello(): void;
}

// using interface in the function
function greet(person: Person) {
  console.log(
    `Hello I am ${person.firstName} ${person.lastName}, I am ${person.age} Years Old`,
  );
  person.sayHello();
}

// using interface defining some values
const Jhon: Person = {
  firstName: "Jhon",
  lastName: "Doe",
  age: 30,
  sayHello() {
    console.log("Hii There");
  },
};

// one more person instance with different values
const Michel: Person = {
  firstName: "Michel",
  lastName: "Kickson",
  age: 33,
  sayHello() {
    console.log("How Are you doing?");
  },
};

// call the function and pass the person object
greet(Jhon);
greet(Michel);

// output :-
// Hello I am Jhon Doe, I am 30 Years Old
// Hii There
// Hello I am Michel Kickson, I am 33 Years Old
// How Are you doing?
```

## Interface for Classes

- here is the example of interface for classes 👇.

```ts
// Interface for a class
interface Vehicle {
  // as we are not returning any value from the function that is why void is annoted for the function.
  start(): void;
  stop(): void;
}

// Class Implementing the Interface

// and here we are using keyword `implements` not extends.
// to implement/define the function call.
class Car implements Vehicle {
  // start function
  start() {
    console.log("Car Started ");
  }

  // stop function
  stop() {
    console.log("Car Stopped");
  }
}

// Usage
const myCar = new Car();
myCar.start();
myCar.stop();
```

## Declaration Merging :-

- Once an Interface is declared, it cannot be directly modified.
- However, Typescript allows what is informally referred to as `declaration merging` or `interface extension`, which is often misconstructed as `re-opening`.

- Declaration merging in Typescript refers to the ability to extend or agument an existing declaration, including interfaces.
- This can be useful when you want to add new properties or methods to an existing interface without modifying the original declaration.

- Here is the example of it 👇

```ts
// Original Interface
interface Car {
  brand: string;
  start(): void;
}

// Declaration merging (interface extension)
interface Car {
  model: string;
  stop(): void;
}

// Usage of the extended interface
const myCar: Car = {
  brand: "Tata",
  model: "Siera",
  start() {
    console.log("Car Started");
  },
  stop() {
    console.log("Car Stopped");
  },
};
myCar.start();
myCar.stop();

// output :-
// Car Started
// Car Stopped
```
