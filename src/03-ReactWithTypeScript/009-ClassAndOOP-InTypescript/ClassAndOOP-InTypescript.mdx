## Class Properties Annotations

- You can annotate class properties with a type.
- This allows you to define the data type of the property and ensure that it is always consistent.

- here is the example :-

```ts
class Person {
  // we can create the types in the class itself.
  name: string;
  age: number;

  // and then specify this types in the constructor too.
  constructor(name: string, age: number) {
    this.name = name;
    this.age = age;
  }
}

// now we will create an instance of the class
// and passing the name and age parameter to it.
const person = new Person("John", 24);
console.log(person);

// the console will gives us the result like this :-
// Person { name: "John", age: 24 }
```

## Access Modifiers

- JavaScript class members are generally public and accessible, but modern JavaScript also supports `#private` fields and methods.
- The `this` keyword refers to the current receiver and is unrelated to access modifiers; closures are not required to use it.

- but anyways we will talk about typescript , so what are access modifiers or simply modifiers

- In Typescript, you can use access modifiers to control the visibility of class members (properties and methods).
- Access modifiers determine the ways in which class members can be accessed from within and outside the class.

- so we have `three types of access modifiers in Typescript`.
  - Public
  - Private
  - Protected

- Public Access Modifier :-
  - Members marked as `public can be access from anywhere`, both `inside and outside the class`.

- Private Access Modifier :-
  - Members marked as `private can only accessed from within the class they are defined in`.

- Protected Access Modifier :-
- Members marked as `protected can be accessed from within the class they are defined in, as well as any subclasses that extended the class`.

```ts
class Animal {
  // defining types for the variables with the access modifiers
  public name: string;
  private age: number;
  protected specifes: string;

  // constructor function and accepting the parameters with its types
  constructor(name: string, age: number, specifes: string) {
    this.name = name;
    this.age = age;
    this.specifes = specifes;
  }

  // now we will create some functions or methods to read the values

  // to get the name
  public getName(): string {
    return this.name;
  }

  // to get the age
  // we have made the function protected so that the age parameter will be accesible in other classes.
  // via this function
  protected getAge(): number {
    return this.age;
  }

  // to get the species
  protected getSpecifes(): string {
    return this.specifes;
  }
}

// now here is the another class that extends the Animal class
// this is specially for the Dog Category
class Dog extends Animal {
  constructor(name: string, age: number) {
    // The super() call invokes the Animal constructor,
    // so in Animal constructor specifes is also there , we are passing as "Dog".
    super(name, age, "Dog");
  }

  // so here as you can see that we are accessing the Animal class functions in the different class
  // which is actually extending the Animal class so that's why we can access the data
  public getInfo(): string {
    return `${this.getName()} is a ${this.getSpecifes()} and age is ${this.getAge()} Years old.`;
  }
}

// to use the class Dog
const shepard = new Dog("German Shepard", 10);
console.log(shepard);

// output :- Dog { name: 'German Shepard', age: 10, specifes: 'Dog' }
```

## Getters and Setters :-

- Getters and Setters are used to access and modify class properties.
- Getters and Setters allow you to define a property in a class that looks like a simple variable from the outside but internally has additional logic for getting and setting the value.
- so how this will look like , here is an example 👇

```ts
class MyClass {
  // define a private variable , initial value will be zero annoted type will be number only.
  private _myProperty: number = 0;

  // now to get the value of the private variable we will use `get` keyword before function/method.
  // this will be getter as we are
  get myProperty(): number {
    return this._myProperty;
  }

  // to set the value , we will use `set` keyword before function/method.
  set myProperty(value: number) {
    if (value < 0) {
      throw new Error("Value cannot be negative");
    }
    // now passing/storing the value in the private variable
    this._myProperty = value;
  }
}

// instance of the class
const myInstance = new MyClass();

// so to use the `myInstance`
console.log(`Current Value: ${myInstance.myProperty}`);
// output of the console, when run's first time :- Current Value: 0

// so the above code console is for to get the value
// but what if we want to set the value , here is the code of it 👇
myInstance.myProperty = 10;
console.log(`after setting value : ${myInstance.myProperty}`);
// output of the console, after setting value : 10
```
