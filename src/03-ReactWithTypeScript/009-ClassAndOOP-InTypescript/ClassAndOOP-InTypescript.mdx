### Class Properties Annotations

- You can annotate class properties with a type.
- This allows you to define the data type of the property and ensure that it is always consistent.

- here is the example :-

```ts
class Person {
  // we can create the types in the class itself.
  name: string;
  age: number;

  // and then specify this types in the constructor too.
  constructor(name: string, age: number) {
    this.name = name;
    this.age = age;
  }
}

// now we will create an instance of the class
// and passing the name and age parameter to it.
const person = new Person("John", 24);
console.log(person);

// the console will gives us the result like this :-
// Person { name: "John", age: 24 }
```
